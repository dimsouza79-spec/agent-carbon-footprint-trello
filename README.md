# Agente de Organização de Tarefas (Trello + Gemini)

Projeto desenvolvido para o desafio da DIO, focado na criação de um agente inteligente de IA integrado com o Trello para gestão de tarefas e produtividade.

## 🚀 O que o agente faz
- Lista os cartões e listas do quadro do Trello ("DIO").
- Permite gerir o fluxo de tarefas entre "A fazer", "Em andamento" e "Concluído".
- Utiliza o SDK oficial do Google Gemini e ferramentas de integração personalizadas.

## 🛠️ Ferramentas Utilizadas
- **Google GenAI SDK** (`gemini-3.8-flash`)
- **Py-Trello** (API Client para o Trello)
- **Python 3.14+**
